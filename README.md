# Portfolio Website

This repository contains a responsive personal portfolio website for Abdulrahman Galal Abdulsalam, a third-year cybersecurity student.

## Features
- Modern cyber-themed design
- Responsive layout for mobile, tablet, and desktop
- Sections for About, Skills, Projects, Certificates, and Contact
- Ready-to-edit placeholder content for personal details

## Files
- `index.html` — main structure
- `styles.css` — visual design and responsiveness
- `script.js` — menu and reveal animations

## Customize
Open `index.html` and replace the placeholder text with your real:
- name
- email
- phone number
- Facebook / LinkedIn / GitHub links
- project details
- certificate names

## Local preview
Open `index.html` directly in a browser, or use a local web server such as:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
